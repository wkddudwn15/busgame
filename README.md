# busgame

2Dドット絵・一人称固定視点で進行する、バスを舞台にしたミステリーゲームです。

プレイヤーは車内の乗客が語る「最期の記憶」や、物語の中で集めた単語カードを手がかりに、限られた時間の中で自分がどこへ向かうべきかを推理します。

> **開発中のプロジェクトです。**  
> 現在は Phase 3 まで実装・動作確認済みです。

---

## ゲーム概要

- 2Dドット絵
- 一人称固定視点
- LEFT / FRONT / RIGHT の3方向を切り替えて車内を観察
- バスはリアルタイムで進行
- 乗客の記憶から情報を集める
- 文章中の単語をクリックして「単語カード」を取得
- 取得した情報をもとに推理を組み立てる
- 降車場所や推理内容によって複数のエンディングへ分岐

ゲーム内の時間は通常画面だけでなく、記憶や各種調査画面を開いている間も進行します。  
時間が止まるのは Pause 中のみです。

## 単語カードシステム

物語中の一部の単語は、マウスを乗せると反応します。

- 通常時: 本文と同じ見た目
- Hover: 黄色 + 下線
- 取得後: 淡い青
- 取得済みの単語を再度クリックしても重複取得しない
- 同じ情報を表す語は、必要に応じて同じ `CollectibleWordData` を共有

クリックできる単語が必ずしも「正解」とは限りません。  
重要情報、補助情報、人物情報、ダミー、ミスリードを同じ仕組みで扱います。
